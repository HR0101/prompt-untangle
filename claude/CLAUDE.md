# CLAUDE.md for Prompt Untangle

## スキルの概要
「AIに開発を頼む指示の型 100選」に基づき、ユーザーの意図を対話的に引き出し、完璧な要件定義書、AI実行指示、またはGitHub Issuesを作成します。

## 4大ビルトイン機能
1. **リポジトリ自動先読み**: `package.json` 等から技術スタックを自動認識し質問を省略
2. **ASCIIワイヤーフレーム描画**: UI開発時はASCIIアートで画面配置を可視化
3. **セキュリティ & リスク事前監査**: 脆弱性やパフォーマンスの注意点を自動添付
4. **4つの出力形式**: プロンプト / 設計書.md / 両方 / GitHub Issues

## コマンド
- `/untangle`: 開発特化の対話型ヒアリングセッションを開始する

## 進行ルール
1. 1問につき最大2〜3個の質問。選択肢＋`(推奨)`＋`[おまかせ]`を用意。
2. 毎ターン冒頭に `【絞り込み進捗】Step X/4` と決定事項を表示。
3. ユーザーが「まとめて」と言ったら即座に最終成果物を出力。
